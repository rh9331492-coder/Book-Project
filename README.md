# 📚 Book-Project

A modern book management web application built with **Next.js**.

## 🚀 Live Demo

🔗 **Live Website:**https://rh9331492-coder.github.io/Book-Project/
## 🛠️ Technologies

* Next.js
* React
* TypeScript
* Tailwind CSS
* JavaScript

## 📦 Getting Started

First, run the development server:

```bash
npm run dev
```

Open http://localhost:3000 with your browser to see the result.

## ✨ Features

* 📚 Browse books
* 🔍 View book details
* 📖 Dynamic book details page
* 📱 Responsive design
* ⚡ Fast performance with Next.js

## 🚀 Deploy

This project can be deployed easily using **Vercel**.
